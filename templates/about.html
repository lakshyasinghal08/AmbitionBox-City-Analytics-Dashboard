THE PIPELINE

A full data science lifecycle

Four stages took this project from a public website to the insights you can explore right here.

STEP 01

Data collection

Company profiles were web-scraped from AmbitionBox across 10 major Indian hiring hubs — Mumbai, Bangalore, Pune, Hyderabad, Chennai, Ahmedabad, Noida, Jaipur, Gurugram and Indore.

94,580 raw listings
STEP 02

Data preprocessing

The ten city files were merged, 30,370 exact duplicates removed, and the tangled “other details” text parsed into clean columns — industry, size, type, age and location — with numeric ages extracted and missing values handled.

64,210 tidy records
STEP 03

Data analysis

Ratings, ages, sizes and ownership types were profiled across 84 industries and 371 locations to surface distributions, averages and the factors that actually drive company ratings.

84 industries • 371 cities
STEP 04

Data visualization

It all comes together in this application — a fast, filterable explore view and a comprehensive insights dashboard where every filter interaction instantly re-renders the analytics.

12 interactive views
Technology Stack
  • Backend
    Python 3 • Flask

    Lightweight web server, in-memory Pandas caching, and high-speed JSON REST APIs for sub-10ms filter responses.

  • Data Engine
    Pandas • NumPy • RegEx

    Deduplication algorithm, string parsing of unstructured listing tokens, and multi-dimensional aggregation.

  • Frontend
    Vanilla JavaScript • Bootstrap 5 • Custom CSS

    Dark glassmorphism design system, responsive grid, dynamic multi-select filters, and client-side sorting.

  • Charts
    Chart.js 4.4

    Dynamic responsive canvas graphics rendered with dark-theme color tokens and hover tooltips.
