# AmbitionBox City Analytics Dashboard

An interactive data visualization and web application designed to analyze and explore corporate workplace ratings across multiple cities using the AmbitionBox dataset. 

## About the Project
This project processes raw city-wise company data to build an end-to-end data analytics dashboard. It features global comparisons across cities alongside dynamic, search-triggered visualizations to evaluate company ratings, employee counts, and industry distributions.

## Key Features
* **Global City Overview:** Fixed charts comparing average company ratings and total company counts across all cities.
* **City Deep-Dive Analytics:** Interactive search capability that instantly generates dedicated charts for top-rated companies and industry shares for the selected city.
* **Corporate Directory:** A fully responsive data table at the bottom of the dashboard listing company names, ratings, and detailed attributes.
* **Tech Stack:** Built using Python, Flask, Pandas, Bootstrap, and Chart.js.
